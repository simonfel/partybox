# Ship an original Joke Boat-inspired game

Milestone 2 — comedy expansion

Working title: Ship Happens. Build word contribution, guided joke setup/punchline writing, performance/reveal, voting, and a final remix round.

Acceptance criteria:
- [ ] Reuse room identities, TV/controller layout, and pacing controls.
- [ ] Generous adjustable writing time.
- [ ] Clear setup → punchline composition UI.
- [ ] Original setups and nautical art direction.
- [ ] Optional read-aloud with a text fallback.
- [ ] Players can remix earlier jokes in the final round.
- [ ] Return to the shared lobby without reconnecting.
