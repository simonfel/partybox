# Build personalized horror trivia and verified topic packs

Milestone 3 — trivia

Working title: Last Call. Original horror game show with trivia, survival minigames, and a final escape.

Acceptance criteria:
- [ ] Each player contributes up to three topics before play.
- [ ] Merge duplicates and balance representation across players.
- [ ] Configure difficulty and language; select categories between rounds.
- [ ] Prepare sourced, checked answers and spare questions before play.
- [ ] Challenge/skip ambiguous questions without corrupting scoring.
- [ ] No live AI request blocks a timed round.
- [ ] Survival minigames and finale keep eliminated players involved.
- [ ] Original names, characters, questions, sound, and artwork.
