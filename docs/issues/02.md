# Punchline: complete the first comedy game

Milestone 1 — first playable game

Original Quiplash-inspired game with original prompts and branding.

Acceptance criteria:
- [ ] Each player receives two prompts per round with paired opponents.
- [ ] Answers remain private until their matchup is revealed.
- [ ] Eligible players vote anonymously; authors cannot vote.
- [ ] Duplicate submissions and stale commands cannot award extra points.
- [ ] Missing answers cannot block the game.
- [ ] Results, final scores, and return to lobby work.
- [ ] 60/120/180/300 second writing timers; pause, resume, and +30 seconds.
- [ ] At least one full multi-device game passes.
