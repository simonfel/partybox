# Shared rooms, TV display, and phone controllers

Milestone 1 — foundation

Create persistent rooms, QR/code joining without accounts, separate display and host roles, and resumable player sessions.

Acceptance criteria:
- [ ] 3–8 players join from independent phones.
- [ ] TV and controller views receive only authorized data.
- [ ] Refreshing preserves identity, scores, and phase.
- [ ] Host token is separate from the room code.
- [ ] Host can manage the lobby from their phone.
- [ ] Room expires after 24 hours.
- [ ] Real-device reconnection and TV checks pass.
